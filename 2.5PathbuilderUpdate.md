# Stage 2.5.1 PathBuilder Migration

## Problem
Stage 2.5.1 (Transcript Validation) fails for competitor/creator analysis types due to path mismatch:
- **Stage 2.5 writes**: `/data/clients/{client}/competitors/{target}/...` (uses PathBuilder)
- **Stage 2.5.1 reads**: `/data/clients/{client}/hashtags/{target}/...` (uses construct_path with hardcoded "hashtags")

Error: `selection_manifest.json not found at /data/clients/rollo/hashtags/gnclivewell/top_top/selection_manifest.json`

## Root Cause
`construct_path()` in `ml_pipeline/stage2_content_analysis/utils.py` has hardcoded path:
```python
base_path = f"{data_root}/clients/{client_id}/hashtags/{hashtag_clean}/{analysis_mode}_{selection_strategy}"
                                              ^^^^^^^^^ HARDCODED
```

Missing:
1. `analysis_type` parameter
2. Proper target sanitization (only strips `#`, not `@`)

## Discovery Summary

### construct_path() Usage Locations
| File | Line | file_type | Returns |
|------|------|-----------|---------|
| transcript_validation.py | 182 | selection_manifest | `{base}/selection_manifest.json` |
| transcript_validation.py | 202 | validation_cache | `{base}/content_taxonomies/transcript_validation_cache.json` |
| run_stage_2_7.py | 149 | taxonomy | `{base}/content_taxonomies/{hashtag}_taxonomy.json` |

**Total**: 3 calls across 2 files

### PathBuilder Comparison
- **PathBuilder** (foundation/paths.py): Dynamic, uses `sanitize_target()`, supports all 3 analysis types
- **construct_path()** (utils.py): Hardcoded "hashtags", incomplete sanitization, legacy code

## Solution: Replace construct_path() with PathBuilder

### File 1: ml_pipeline/stage2_content_analysis/transcript_validation.py

**Add import (after line 16):**
```python
from foundation.paths import PathBuilder
```

**Replace lines 182-185:**
```python
# OLD
manifest_path = construct_path(
    client_id, hashtag, analysis_mode, selection_strategy,
    file_type="selection_manifest"
)

# NEW
path_builder = PathBuilder()
target_dir = path_builder.get_target_dir(
    client_id=client_id,
    analysis_type=analysis_type,
    target=hashtag,
    analysis_mode=analysis_mode,
    selection_strategy=selection_strategy
)
manifest_path = str(target_dir / "selection_manifest.json")
```

**Replace lines 202-205:**
```python
# OLD
cache_path = construct_path(
    client_id, hashtag, analysis_mode, selection_strategy,
    file_type="validation_cache"
)

# NEW (reuse target_dir from above)
cache_path = str(target_dir / "content_taxonomies" / "transcript_validation_cache.json")
```

### File 2: run_stage_2_7.py

**Update import (line 24):**
```python
# OLD
from stage2_content_analysis.utils import construct_path

# NEW
from foundation.paths import PathBuilder, sanitize_target
```

**Add CLI argument (after line 77):**
```python
parser.add_argument(
    '--analysis-type',
    required=True,
    choices=['hashtag', 'competitor', 'creator'],
    help='Analysis type (hashtag, competitor, or creator)'
)
```

**Replace lines 149-154:**
```python
# OLD
taxonomy_path = construct_path(
    client_id=args.client,
    hashtag=hashtag,
    analysis_mode=args.analysis_mode,
    selection_strategy=args.selection_strategy,
    file_type="taxonomy"
)

# NEW
path_builder = PathBuilder()
target_dir = path_builder.get_target_dir(
    client_id=args.client,
    analysis_type=args.analysis_type,
    target=hashtag,
    analysis_mode=args.analysis_mode,
    selection_strategy=args.selection_strategy
)
target_sanitized = sanitize_target(hashtag, args.analysis_type)
taxonomy_path = str(target_dir / "content_taxonomies" / f"{target_sanitized}_taxonomy.json")
```

## Implementation Notes
- Convert Path objects to str() for compatibility with existing code
- PathBuilder returns `pathlib.Path`, most file operations accept both Path and str
- `sanitize_target()` handles prefix stripping, lowercasing, special chars (foundation/paths.py:200-239)
- No changes to utils.py needed (construct_path() remains for backward compatibility but unused)
