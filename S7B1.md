## Summary

Cluster path percentages in `winning_formulas.json` are calculated using **K-Means total_videos** (all videos) as denominator, but **only counting paths from top performers** (80% subset), creating mathematical inconsistency.

## Root Cause Analysis

### Hypothesis A: extract_cluster_paths() Uses Wrong Denominator

**Location**: `stage7_llm_analysis.py:596-668`

```python
def extract_cluster_paths(bucket_path: str, window_types: List[str]) -> List[dict]:
    # Load K-Means files
    kmeans_data_by_window = {}
    for window_type in window_types:
        kmeans_path = os.path.join(ml_analysis_dir, f'{window_type}_kmeans_analysis.json')
        with open(kmeans_path, 'r') as f:
            kmeans_data_by_window[window_type] = json.load(f)

    # Build cluster paths
    paths = []
    for video_id, window_cluster_map in video_clusters.items():
        path = [window_cluster_map[wt] for wt in window_types]
        paths.append(path)

    # Count frequencies
    path_counter = Counter(tuple(p) for p in paths)
    total_videos = len(paths)  # ← Should be 27 for bucket 18-33s

    for path_tuple, frequency in path_counter.most_common():
        percentage = (frequency / total_videos) * 100  # ← Using correct denominator
        cluster_paths.append({
            'path': list(path_tuple),
            'frequency': frequency,
            'percentage': percentage
        })
```

**Issue**: If `total_videos = len(paths) = 27`, then percentages should be correct.

**BUT**: K-Means files might contain ALL 47 videos (top + bottom), while Stage 7 only iterates over top performers.

### Hypothesis B: K-Means Files Contain All Videos, Stage 7 Filters to Top Only

**Check Required**:

**Expected**:
- `hook_kmeans_analysis.json` → `total_videos: 47` (all videos)

**Contradiction**: If `len(paths) = 47`, then percentages would be correct (8/47 = 17.0%).

**Resolution**: Stage 7 must be filtering paths AFTER extraction.

### Hypothesis C: Stage 7 Filters to Top Performers After Path Extraction

**Possible filtering locations**:
1. `extract_cluster_paths()` - filters by label (top vs. bottom)
2. `run_phase2_synthesis()` - receives pre-filtered paths
