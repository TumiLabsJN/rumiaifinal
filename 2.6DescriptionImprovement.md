## Executive Summary

After analyzing 50 real TikTok captions from the vitamin hashtag dataset, we've identified **2 critical gaps** in our current caption analysis implementation that prevent Stage 7 reports from detecting major engagement patterns:

1. **Trend Participation** (appears in 30% of captions) - Currently not captured
2. **Collaboration Type** (appears in 20% of captions) - Currently only captured as boolean

Current implementation has **8 fields** that work correctly. This document proposes adding **2 new fields** to capture engagement drivers that are prevalent in real data but missing from our analysis.

## Part 3: Proposed Solution

### Proposed Schema Changes

**Add 2 new fields to `caption_analysis` object**:

```json
{
  // EXISTING 8 FIELDS (keep as-is):
  "hook_type": "statement",
  "cta_type": "follow",
  "brand_mention_present": true,
  "influencer_tag_present": true,
  "emoji_usage": "some",
  "caption_length": "short",
  "hashtag_count": 10,
  "hashtag_placement": "end",

  // NEW FIELD 1: Trend Participation
  "trend_participation": true,  // Does caption mention "trend", "meme", "challenge"?

  // NEW FIELD 2: Collaboration Type
  "collaboration_type": "inspired_by"  // Type of creator collaboration (enum)
}
```

**New Field Definitions:**

#### Field 9: `trend_participation` (boolean)

**Definition**: Does the caption explicitly mention participation in a trend, meme, or challenge?

**Detection Logic**:
```python
# Keywords (case-insensitive):
trend_keywords = ["trend", "meme", "challenge"]

# Detection:
trend_participation = any(keyword in caption.lower() for keyword in trend_keywords)

# Examples:
"VITAMINA TREND" → true
"Vitamina animation meme/trend" → true
"Maybe take your vitamins" → false
```

**Validation Examples**:
- ✅ TRUE: "VITAMINA TREND || idea : not mine" (#7)
- ✅ TRUE: "Am I late for the trend? 😭😭" (#18)
- ✅ TRUE: "VITAMINA MEME: MITCHELL..." (#26)
- ✅ FALSE: "Maybe take your vitamins" (#3)
- ✅ FALSE: "Hyperpigmentation<<<Vitamin c 😍😍" (#4)

#### Field 10: `collaboration_type` (enum)

**Definition**: Type of creator collaboration indicated in caption.

**Enum Values**:
```python
collaboration_type = "none" | "inspired_by" | "duet_collab" | "credit_via" | "shoutout"
```

**Detection Logic**:
```python
# Markers (case-insensitive):
inspired_by_markers = ["ib:", "ib ", "idea:", "inspired by"]
duet_collab_markers = ["collab w/", "collab with", "ft:", "ft ", "fake collab", "duet"]
credit_via_markers = ["via:", "via ", "by:", "by ", "oc:", "crdts to", "credits to"]

# Priority order (first match wins):
if any(marker in caption.lower() for marker in inspired_by_markers):
    return "inspired_by"
elif any(marker in caption.lower() for marker in duet_collab_markers):
    return "duet_collab"
elif any(marker in caption.lower() for marker in credit_via_markers):
    return "credit_via"
elif "@" in caption:  # Generic tag with no context marker
    return "shoutout"
else:
    return "none"
```

**Validation Examples**:
- ✅ "inspired_by": "ib: @det.monoka & @LEO" (#16)
- ✅ "duet_collab": "collab w/@username" (#32)
- ✅ "credit_via": "via : @straymor" (#3)
- ✅ "shoutout": "@BioEmblem #vitamind3" (#46)
- ✅ "none": "Maybe take your vitamins" (#3, after removing "@straymor" from consideration due to "via" marker)

## Part 6: Alternative Approaches Considered

### Alternative 1: Post-Processing (Regex-based)

**Approach**: Don't use LLM, add Python regex patterns to extract fields from caption text

**Pros**:
- Free (no LLM cost)
- Deterministic (same caption always produces same result)
- Fast (no API latency)

**Cons**:
- Brittle: Requires maintaining regex patterns for every edge case
- Language barriers: Breaks on non-English captions (#17, #29, #33, #47)
- Context-blind: Can't distinguish "trend" (noun) vs "trending" (adjective)
- Example failure: "Am I late for the trend?" (#18) → Regex might miss "trend" if not at start/end

**Verdict**: ❌ **REJECTED** - LLM approach is more robust for multi-language, context-aware detection

---

### Alternative 2: Do Nothing (Current 8 Fields Sufficient)

**Approach**: Keep current 8-field schema, don't add new fields

**Pros**:
- Zero implementation cost
- No risk of breaking existing system
- Current 8 fields already work correctly

**Cons**:
- **Misses 30% of engagement drivers**: Trend participation invisible
- **Misses 20% of engagement drivers**: Collaboration type nuance lost
- **Limits Stage 7 reports**: Can't answer strategic questions about trends/collabs
