## Executive Summary

**Issue**: The `supplementary_insights.cross_window_patterns` field is empty in all Stage 7 outputs, despite MLPlanningv2.md specification requiring temporal progression patterns (e.g., "Energy Crescendo" where energy builds from hook → middle → closing).

**Root Cause**: **Dual bug** across Stage 6 and Stage 7:
1. **Stage 6 Bug**: Cross-window features have null distribution data (checked wrong CSV)
2. **Stage 7 Bug**: `generate_cross_window_patterns()` function looks in wrong location (window centroids instead of video-level RF)

**Impact**: Missing 30% of actionable insights - creators don't learn about temporal progressions like "energy should build throughout video"

**Fix Strategy**: Hybrid fix requiring changes in both Stage 6 (compute distributions from correct CSV) and Stage 7 (fix logic to use video-level RF data)

**Estimated Effort**: 5-8 hours (2-3h Stage 6, 2-3h Stage 7, 1-2h testing)

#### Phase 2.1: Read `generate_cross_window_patterns()` Function

**Current Implementation**:
```python
def generate_cross_window_patterns(window_analyses: dict, rf_video_data: dict) -> List[str]:
    """Extract temporal progression patterns across windows."""

    # Get top RF features to focus on
    top_rf_features = [
        f['feature'] for f in rf_video_data.get('feature_importance', [])[:5]
    ]

    # For each top RF feature, check if it appears in multiple windows
    for feature in top_rf_features:
        window_values = {}

        for window_name, analysis in window_analyses.items():
            # Look for this feature in cluster centroids
            for cluster in analysis.get('clusters', []):
                centroid = cluster.get('centroid', {})
                if feature in centroid:  # ← WRONG!
                    if window_name not in window_values:
                        window_values[window_name] = []
                    window_values[window_name].append(centroid[feature])
```

**ROOT CAUSE #2 IDENTIFIED**: Lines 582-589 try to find cross-window features in Phase 1 window cluster centroids!

**Why This is Wrong**:
- Cross-window features like `hook_to_middle_energy_delta` represent **relationships between windows**
- They only exist at the **video level** (comparing hook to middle)
- They **cannot exist** in individual window centroids (hook centroid has hook features only)
- Function is looking in completely wrong location!

**Example to illustrate the logic flaw**:
```
Feature: hook_to_middle_energy_delta = middle_energy - hook_energy

Window centroids:
- hook centroid: {energy_level: 0.45, word_count: 14, ...}  ← No "delta" here!
- middle_1 centroid: {energy_level: 0.65, word_count: 52, ...}  ← No "delta" here!

Video-level RF data:
- feature_importance: [
    {feature: "hook_to_middle_energy_delta", importance: 0.018, ...}  ← Delta is HERE!
  ]
```

The function should use `rf_video_data['feature_importance']` directly, not search in window centroids.

                'low': low_threshold

                'medium_percentage': float(top_med_pct),
                'low_percentage': float(top_low_pct)

```python
def generate_cross_window_patterns(window_analyses: dict, rf_video_data: dict) -> List[str]:
    """
    Extract temporal progression patterns from video-level RF cross-window features.

    Cross-window features (e.g., hook_to_middle_energy_delta) exist ONLY in video-level
    RF analysis, not in individual window centroids.

    Args:
        window_analyses (dict): Phase 1 window analyses (NOT USED in new implementation)
        rf_video_data (dict): Video-level RF data containing cross-window features

    Returns:
        List[str]: Human-readable cross-window pattern descriptions
            [
                "hook_to_middle_energy_delta: increases (top avg: 0.15, bottom avg: -0.08, gap: 0.23, RF importance: 0.018)",
                "energy_progression_slope: Positive trend (slope: 0.12, RF importance: 0.020)",
                ...
            ]

    Note: Returns empty list if no valid cross-window features found (graceful degradation)

    Source: TI §4.8 (revised implementation for S7B2 fix)
    """
    patterns = []

    # Filter RF features to cross-window only (by keyword matching)
    cross_window_keywords = ['delta', 'progression', 'slope', 'consistency', 'variance', 'trend']

    # Exclude within-window variance features (e.g., "middle_2_scene_duration_variance")
    # Only include features that represent relationships BETWEEN windows
    cross_window_features = [
        f for f in rf_video_data.get('feature_importance', [])
        if any(keyword in f['feature'] for keyword in cross_window_keywords)
        and f.get('top_performer_avg') is not None  # Skip features with null data
        and not f['feature'].startswith('hook_')  # Exclude hook-only features like "hook_energy_variance"
        and not f['feature'].startswith('middle_')  # Exclude middle-only features
        and not f['feature'].startswith('closing_')  # Exclude closing-only features
        # Only include features that span multiple windows (contain "to", "cross", or end with progression/slope)
        and ('_to_' in f['feature'] or 'cross_window' in f['feature']
             or f['feature'].endswith('progression') or f['feature'].endswith('_slope'))
    ]

    # If no valid cross-window features, return empty (graceful degradation)
    if not cross_window_features:
        logger.warning("No valid cross-window features with distribution data found. "
                      "This may indicate Stage 6 did not compute distributions for derived features.")
        return []

    logger.info(f"Found {len(cross_window_features)} valid cross-window features")

    # Generate human-readable patterns from top cross-window features
    for feature_data in cross_window_features[:5]:  # Top 5 cross-window features
        feature_name = feature_data['feature']
        top_avg = feature_data['top_performer_avg']
        bottom_avg = feature_data['bottom_performer_avg']
        gap = feature_data['gap']
        importance = feature_data['importance']

        # Format pattern description based on feature type
        if '_to_' in feature_name and 'delta' in feature_name:
            # e.g., "hook_to_middle_energy_delta" or "middle_to_closing_delta"
            parts = feature_name.replace('_delta', '').split('_to_')
            from_window = parts[0]
            to_window = parts[1] if len(parts) > 1 else 'closing'

            if top_avg > 0.05:
                direction = "increases"
            elif top_avg < -0.05:
                direction = "decreases"
            else:
                direction = "remains stable"

            pattern = (f"{feature_name}: {direction} from {from_window} to {to_window} "
                      f"(top avg: {top_avg:.2f}, bottom avg: {bottom_avg:.2f}, "
                      f"gap: {gap:.2f}, RF importance: {importance:.3f})")

        elif 'progression' in feature_name or 'slope' in feature_name:
            # e.g., "energy_progression_slope"
            feature_base = feature_name.replace('_progression', '').replace('_slope', '')

            if top_avg > 0.05:
                trend_desc = "Positive trend (builds throughout video)"
            elif top_avg < -0.05:
                trend_desc = "Negative trend (decreases throughout video)"
            else:
                trend_desc = "Flat (no progression)"

            pattern = (f"{feature_base} progression: {trend_desc} "
                      f"(slope: {top_avg:.3f}, RF importance: {importance:.3f})")

        elif 'consistency' in feature_name or 'variance' in feature_name:
            # e.g., "emotion_consistency_cross_window"
            feature_base = feature_name.replace('_consistency', '').replace('_variance', '').replace('_cross_window', '')

            if 'consistency' in feature_name:
                # Higher consistency = better
                if top_avg > bottom_avg:
                    interpretation = "more consistent"
                else:
                    interpretation = "more varied"
            else:  # variance
                # Lower variance = more consistent
                if top_avg < bottom_avg:
                    interpretation = "more consistent"
                else:
                    interpretation = "more varied"

            pattern = (f"{feature_base} across windows: Top performers are {interpretation} "
                      f"(top avg: {top_avg:.2f}, bottom avg: {bottom_avg:.2f}, "
                      f"gap: {gap:.2f}, RF importance: {importance:.3f})")

        else:
            # Generic formatting for other cross-window features
            pattern = (f"{feature_name}: Top avg {top_avg:.2f} vs Bottom avg {bottom_avg:.2f} "
                      f"(gap: {gap:.2f}, RF importance: {importance:.3f})")

        patterns.append(pattern)
        logger.debug(f"Generated pattern: {pattern}")

    logger.info(f"Generated {len(patterns)} cross-window patterns")
    return patterns
```
