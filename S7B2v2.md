## Common Issues & Solutions

### Issue 1: "ModuleNotFoundError: No module named 'config'"
**Solution:** Ensure you're using venv and PYTHONPATH is set:
```bash
export PYTHONPATH=/home/jorge/rumiaifinal
venv/bin/python scripts/...
```

### Issue 2: Stage 3 fails with "unrecognized arguments: --strategy"
**Solution:** The OLD Stage 3 doesn't have --strategy. You're using the wrong version. Ensure you're running the UPDATED script.

### Issue 3: Stage 4 validation error "Expected 135 columns, found 129"
**Solution:** Stage 3 didn't run with the new code. Re-run Stage 3 with --strategy argument.

### Issue 4: Stage 6 still shows NULL distributions
**Possible causes:**
- Stage 5 models weren't retrained (they expect old schema)
- Stage 6 cache is stale
**Solution:** Delete `ml_analysis/` and `models/` directories, re-run Stages 4-6

### Issue 5: "TypeError: ufunc 'isnan' not supported"
**Solution:** This was fixed with `.astype(float)` in Stage 3. If still occurring, check if you're using the updated code.
